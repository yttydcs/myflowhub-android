- `MyFlowHub-Core` 已发布 `v0.4.0`。
- 本次将 `hubmobile` 依赖链统一对齐到本轮下游发布版本：
  - `myflowhub-core v0.4.0`
  - `myflowhub-sdk v0.1.4`

## 设计决策与权衡
- 不改 `hubmobile` 业务逻辑，仅做依赖版本对齐。
- Android 仓当前已存在本地 `Server` replace 策略，本次将 `SDK` 也收口为同类本地 replace：
  - 优点：便于在 meta-workspace / CI 中联调与 `GOWORK=off` 验证
  - 代价：仓库继续保持“依赖同级仓”的开发态构建模式，而非单仓独立构建
- 该策略与当前 Android 仓的开发方式一致，因此本次选择保留，而不是临时验证后再移除。
